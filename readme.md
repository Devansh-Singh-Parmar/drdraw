#DrDraw

A fun drawing game for friends! Works like skribbl.io, but with a few twists. You can play with friends in private rooms, or join public rooms to play with random people. The game is free to play and does not require an account.

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Environment variables configured

### Environment Variables

Create a `.env` file in the `server` directory:

```
COHERE_API_KEY=your_cohere_api_key
PORT=5000
NODE_ENV=development
```
